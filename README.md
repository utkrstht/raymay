# raymay
a simple 3d raymarching thing where you can walk and jump and roam around  
this fits under 3kb on a data URI!

you are on a flat checker-board floor thingy and you can move around with wasd,   
camera is controlled by arrow keys! you can jump as well with space, but it's more of a ground slam

# how to run
install the modules!  
`npm i --save-dev terser`

run the builder!  
`node build.mjs`

now, copy `dist/uri.txt` and paste it in your browser's address bar!
